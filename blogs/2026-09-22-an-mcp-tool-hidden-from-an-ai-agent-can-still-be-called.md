PayPal researchers surveyed six of the ten official Model Context Protocol SDKs in a paper published September 18, 2026, finding no documented per-tool authorization path. Filtering a forbidden tool from an agent's listing stopped all 720 model attempts, while a scripted caller ran it anyway.
